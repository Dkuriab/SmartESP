# SmartESP UI

Веб-интерфейс ассистента: схема хода голосового запроса, лента фраз, настройки
колонок, обработчиков, диспетчера и голоса. Говорит с ядром только через
`/api/v1` и `/api/v1/events`. Правила и команды — в [`CLAUDE.md`](CLAUDE.md).

## Сборка

Нужен Node.js.

```bash
cd ui
npm ci && npm run build
```

Результат — `ui/dist`. Ядро само отдаёт его на `/`: достаточно перезапустить
ядро (`cd core && uv run python -m smartesp`) и открыть
`http://127.0.0.1:8765/`. Без сборки ядро показывает страницу с командой сборки.

## Исполнители

Схема показывает всех исполнителей и связи между ними (подпись на стрелке —
условие «Когда вызывать»; связи модели без инструментов — пунктиром,
«неактивна»); у исполнителя, чья модель не прогрелась, — «модель недоступна».
Путь хода, выбранного в ленте, подсвечивается синим до ответившего (без выбора —
ничего). В левой панели —
раздел «Исполнители» с кнопкой «Добавить». В настройках исполнителя: имя, модель,
описание, промпт (у нового — «отвечай голосом…») и «Может передавать» — флажок и
«Когда вызывать» на каждую цель; у модели без инструментов связь можно только убрать.
Лента помечает передачу («→ Большая модель»), в карточке хода — «Передано:
<имя> — <задача>».
У входного исполнителя — переключатели «Кузя может заговорить сам» и «Слушать после
вопроса». Лента помечает объявления («сам»), недоставленные («не доставлено») и
ответы на вопрос Кузи; у колонки со старой прошивкой — подсказка её обновить.
Подробности и правила передачи — в [`../core/README.md`](../core/README.md).

## Схема: раскладка

Схема лежит на общем фоне интерфейса. Узлы можно перетаскивать мышью (выбранный —
и стрелками клавиатуры); места запоминаются в браузере (`localStorage`, по id узла) и
не сбрасываются опросом status. Новые узлы встают на вычисленные места. Кнопка
«Расставить заново» в углу схемы забывает места и подгоняет схему под окно. Без
хранилища (приватное окно) схема работает, но места не запоминает.

## Что работает сейчас и коннекторы

Пока идёт ход, работающее сейчас пульсирует зелёным с подписью под узлом:
исполнитель «думает…» или «говорит», коннектор — имя вызванного инструмента
(«calc…»); от вызвавшего исполнителя к коннектору тянется зелёная стрелка. Это
отдельно от синей подсветки пути выбранного хода. Короткий вызов светится не меньше
1,2 с, потом плавно гаснет; при обрыве связи подсветка снимается сразу. В левой
панели те же блоки отмечены пульсирующей точкой (на узком экране схема мелкая). При
`prefers-reduced-motion` пульса и угасания нет — постоянное кольцо, снимается после
тех же 1,2 с. У исполнителя, чья модель
сейчас в памяти Ollama, — «в памяти» (status перечитывается раз в 5 с).

Коннекторы — столбец под голосом и раздел «Коннекторы» в левой панели:
состояние (готов, запускается, ошибка, выключен), переключатель. На панели
коннектора — состояние, ошибка, инструменты и окружение (значения ключей с
TOKEN, KEY, SECRET, PASSWORD скрыты); значения меняются в `config.yaml`. Лента
помечает вызванные инструменты («🧩 calc», неудачный — красным), карточка хода
перечисляет их все.

## Токен

При первом открытии нужен токен из `~/SmartEsp/token`: откройте
`http://127.0.0.1:8765/?token=<токен>`. Интерфейс запомнит его в браузере и уберёт
из адреса. Если токен неверный, покажется экран «Введите токен».

## Открыть с другого компьютера

В левой панели есть блок «Доступ из сети» — адрес ядра в локальной сети уже с
токеном. Нажмите «Скопировать» и откройте его в браузере другого компьютера
(он должен быть в той же сети).

## Разработка

```bash
npm run dev
```

Vite поднимает интерфейс на своём порту и проксирует `/api` (вместе с
WebSocket) на ядро `127.0.0.1:8765` — ядро должно быть запущено.

После изменения API ядра обновите типы:

```bash
npm run api
```

Команда выгружает `openapi.json` из ядра и пересоздаёт `src/api/schema.ts`.

## Проверки

Перед коммитом: `npm run typecheck && npm run lint && npm test -- --run && npm run build`.
