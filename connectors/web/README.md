# web — интернет (поиск и чтение страниц)

MCP-коннектор SmartESP: даёт Кузе доступ в интернет. Поиск — DuckDuckGo без
ключа (HTML-выдача `html.duckduckgo.com`, регион «Россия»), чтение — текст
страницы без JavaScript. Ответы рассчитаны на пересказ вслух: источник
называется по домену, адреса вслух не читаются.

## Инструменты

- `web_search(query)` — поиск. Для свежих фактов, новостей, цен, курсов и всего,
  чего модель не знает наверняка. Ответ: 2–3 лучших сниппета в виде
  «домен: текст» (сначала с разных сайтов), ниже — все результаты (до 5) с
  заголовком, доменом и адресом, чтобы открыть страницу через `web_read`.
  Тот же список — в `structuredContent`: `{"results": [{"title", "url", "snippet"}]}`.
  Ничего не нашлось — «Ничего не нашлось по запросу «…».»
- `web_read(url)` — текст страницы по ссылке: «Страница с сайта домен: «заголовок».»
  и до 8000 символов главного текста (упрощённый «режим чтения»: без скриптов,
  меню, шапки и подвала, скрытых блоков и списков ссылок). Длиннее — обрезается
  с пометкой «(Дальше текст обрезан.)».

## Ограничения и защита

- Только `http` и `https`; другие схемы — «Открываю только ссылки http и https.»
- Домашняя сеть и сам компьютер недоступны: `localhost`, `*.localhost`, `*.local`,
  `*.home.arpa`, `*.internal`, `*.lan`, имена без точки, а также любые
  частные/служебные адреса (127.0.0.0/8, 10/8, 172.16/12, 192.168/16, 169.254/16,
  100.64/10, ::1, fc00::/7, fe80::/10, fec0::/10, многоадресные; IPv6 со
  встроенным IPv4 — NAT64, 6to4, Teredo, `::ffff:` — проверяется и сам IPv4).
- Запрещены и все адреса самого компьютера — со всех сетевых интерфейсов,
  включая глобальные IPv6 (список обновляется не чаще раза в минуту).
  **Внешний IPv4 роутера не запрещается**: узнать его можно только запросом
  наружу. Если на роутере проброшены порты, страница, ведущая на внешний адрес
  дома, через hairpin NAT дойдёт до проброшенной службы.
- Проверка — на ссылке, на каждом перенаправлении (не больше 3) и при каждом
  подключении: имя разрешается через DNS, все адреса проверяются, подключение
  идёт к проверенному адресу (подмена DNS не помогает). Ответ —
  «Это адрес домашней сети или самого компьютера — такие страницы не открываю.»
- Прокси из окружения (`HTTP(S)_PROXY`) не используются: через прокси адрес
  разрешал бы прокси, и проверка не работала бы.
- Время на запрос — 8 секунд целиком; скачивается не больше 2 МБ по проводу и
  не больше 2 МБ после распаковки (поиск — 1 МБ). Сжатие — только одно, gzip или
  deflate (их и просим в `Accept-Encoding`); распаковка пошаговая с пределом,
  «бомба» обрывается на 2 МБ. Несколько сжатий подряд, br и прочие — отказ
  «Сайт прислал страницу в сжатом виде, который я не читаю.»
- Читаются только `text/html`, `application/xhtml+xml`, `text/plain`.
  Кодировка — из заголовка, иначе из `<meta>`, иначе UTF-8, иначе cp1251.
- Предел частоты: поиск — 10 в минуту, чтение — 20 в минуту; сверх —
  «Слишком много запросов в интернет подряд. Попробуйте через минуту.»
  Ссылки, отклонённые проверкой, предел не тратят.
- DuckDuckGo ответил капчей или отказом по частоте (202, 403, 429) — «Поиск
  сейчас недоступен.», и 5 минут в поиск не ходим. Сеть недоступна — тот же ответ.
  Заголовки поиска — в том же наборе и порядке, что у обычного HTTP-клиента
  (httpx): с другим порядком DuckDuckGo через раз отвечал капчей.

## Переменные окружения

Не нужны. `SMARTESP_CONNECTOR_DATA` не используется: коннектор ничего не хранит
на диске. `_meta.person` не используется.

## Зависимости

`mcp==2.3.0`; `httpcore==1.0.9` — запросы (публичный API: свой сетевой слой с
проверкой адресов и сырое тело для своей распаковки); `httpx==0.28.1` — только
разбор и склейка ссылок; `psutil==7.2.2` — адреса сетевых интерфейсов;
`selectolax==1.0.2` — быстрый разбор HTML (lexbor, без зависимостей).

## Запуск и проверки

```
uv sync
uv run web-mcp          # stdio
uv run pytest -q        # без сети: настоящая защита, подменены только DNS и сокеты
WEB_LIVE=1 uv run pytest -q   # + живой поиск, чтение Википедии и отказ для localtest.me
uv run ruff check && uv run ruff format --check
uv run pyright
```
