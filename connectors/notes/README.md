# notes — заметки и списки для SmartESP

MCP-коннектор (stdio) для «Кузи»: заметки и именованные списки («покупки», «готовка»).

## Инструменты

- `list_add(list, items)` — добавить пункты в список (список создаётся сам);
- `list_show(list)` — показать пункты по порядку;
- `list_remove(list, items)` — вычеркнуть: совпадение без регистра, достаточно части
  («молоко» вычеркнет «молоко 2 л»); если подходит несколько пунктов — не вычёркивает, называет варианты;
- `list_clear(list)` — очистить список; `lists()` — какие списки есть;
- `note_add(text)` — записать заметку с датой и временем;
- `notes_find(query)` — найти заметки (до 5 последних);
- `note_delete(query)` — удалить заметку, если подходит ровно одна.

Имя списка нормализуется (регистр, «ё», пробелы): «Покупки» и «покупки» — один список.
Ответы — короткий русский текст для озвучки.

## Данные

Папка из переменной `SMARTESP_CONNECTOR_DATA` (без неё коннектор не запускается).
Данные раздельно по человеку из `_meta.person` вызова; нет человека — общая папка `home`.

```
<data>/<person>/lists/<имя>.md      пункт — строка «- »
<data>/<person>/notes/YYYY-MM-DD.md заметка — абзац «ЧЧ:ММ текст»
```

Запись атомарная (временный файл + rename). Сети нет.

## Запуск и проверка

```
SMARTESP_CONNECTOR_DATA=~/SmartEsp/connectors/notes uv run notes-mcp
uv run pytest -q && uv run ruff check && uv run ruff format --check && uv run pyright
```
