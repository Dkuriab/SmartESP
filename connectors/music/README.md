# music — музыка на колонках Кузи

MCP-коннектор: музыка из папок Mac, интернет-радио и **звук Mac** (Spotify, Яндекс
Музыка, YouTube — через виртуальное устройство BlackHole) играют **на наших колонках**.
Звук тянет сама колонка (прошивка 0.6.0+, протокол 5), очередь ведёт ядро; коннектор
выбирает, что и где, и зовёт API ядра (`/api/v1/streams`). Дизайн —
`docs/superpowers/specs/2026-11-22-music-design.md`.

Когда на колонке говорят «Кузя», музыка сразу стихает (пауза в самой колонке) и
продолжается через 1,5 с после ответа. Радио и звук Mac во время разговора идут дальше
без звука — после разговора они звучат «сейчас», а не с места паузы.

## Настройки (панель коннектора в приложении)

| Ключ | Что | Пример |
|---|---|---|
| `MUSIC_FOLDERS` | папки, откуда Кузя берёт файлы (только отсюда) | `Музыка=~/Music;Аудиокниги=~/Books` |
| `MUSIC_RADIO` | станции «имя=ссылка» через «;» (поток, `.m3u`, `.pls` или HLS `.m3u8`) | `Джаз=https://…/jazz.mp3` |
| `MUSIC_MAC_DEVICE` | часть имени устройства ввода для «звука Mac»; пусто — `BlackHole` | `Loopback` |

Файлы: MP3, M4A, AAC, FLAC, WAV, OGG/Opus, AIFF. В `smartesp.json` стоит `"core_api": true`:
ядро даёт коннектору адрес и токен своего API (`SMARTESP_URL`, `SMARTESP_TOKEN`).

## Инструменты

| Инструмент | Пример фразы |
|---|---|
| `speaker_music_play(query, speaker, shuffle)` | «включи Кино на кухне», «включи музыку вперемешку» |
| `speaker_radio_play(station, speaker)` | «включи джаз-радио» |
| `speaker_mac_audio_play(speaker)` | «включи звук с Мака на кухне» |
| `speaker_music_pause / resume / next / previous / stop(speaker)` | «пауза», «продолжи», «дальше», «назад», «выключи» |
| `speaker_music_volume(delta, percent, speaker)` | «громче», «тише», «громкость музыки 30» |
| `speaker_music_status()` | «что играет?» |
| `speaker_music_library()` | «какая музыка есть?» |

Колонка: названная в просьбе; иначе та, с которой говорят (`_meta.device` вызова); иначе её
выбирает ядро (единственная с музыкой или колонка последнего разговора).

## Звук Mac через BlackHole

1. Установите виртуальное устройство: `brew install --cask blackhole-2ch` (потом может
   понадобиться перезагрузка или `sudo killall coreaudiod`).
2. Чтобы звук шёл в BlackHole **и** был слышен на Mac: «Настройка Audio MIDI» →
   «+» → «Создать устройство с несколькими выходами» → отметьте BlackHole 2ch и динамики
   Mac (или наушники). В «Системных настройках → Звук → Выход» выберите это устройство.
   Только BlackHole — звук будет только на колонке.
3. **Доступ к микрофону.** Звук с устройства ввода macOS даёт только с разрешения
   «Микрофон» тому, кто запустил ядро (ffmpeg — его дочерний процесс):
   - ядро запущено приложением SmartESP — «Системные настройки → Конфиденциальность и
     безопасность → Микрофон → SmartESP» (macOS спросит при первом «включи звук с Мака»);
   - ядро запущено из терминала (`uv run python -m smartesp`) — то же для Терминала/iTerm.
   Приложение подписано ad-hoc: после пересборки `app/build.sh` разрешение может
   понадобиться дать заново (выключить и включить переключатель).
   Без разрешения macOS не показывает ядру устройства ввода — Кузя так и скажет.
4. Скажите: «Кузя, включи звук с Мака на кухне». Выключить — «Кузя, выключи музыку».

Задержка звука Mac на колонке — около 0,5–1 с (буфер колонки), видео с ним не совпадёт.
