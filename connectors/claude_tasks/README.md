# claude-tasks-mcp — задачи для Клода

MCP-коннектор SmartESP: «Кузя, попроси Клода …» → фоновая задача Claude Code на
Mac в разрешённой папке. Статус — голосом; когда задача кончилась, коннектор
просит ядро сказать это вслух (уведомление `announce`). Работает по stdio.

## Инструменты

| Инструмент | Что делает | Пример ответа |
|---|---|---|
| `task_start(task, folder="")` | Запускает задачу в папке `folder` (имя из настроек, «имя/подпапка» или путь внутри разрешённой); пусто — первая папка. | «Передала Клоду: «почини тесты ядра». Скажу, когда закончит.» |
| `task_status(name="")` | Идёт / готово / готово с отказами / ошибка / отменена и сколько времени; пусто — последняя задача. | «Задача «почини тесты ядра» идёт 5 минут.» |
| `tasks()` | Последние 5 задач. | «Задачи Клода: почини тесты — идёт 2 минуты; обнови readme — готово.» |
| `task_result(name="")` | Короткий итог: первые 2–3 предложения ответа Claude без разметки и кода. | «Починила test_x. Причина — опечатка.» |
| `task_cancel(name)` | Отменяет идущую задачу (процесс Claude останавливается). | «Задача «почини тесты» отменена.» |

Имя задачи — первые слова её текста («почини тесты ядра пожалуйста»); повтор —
с номером («задача 2»). Искать можно по части имени, без учёта регистра; если
подходит несколько — «Уточни: …».

Не больше 2 задач одновременно (на весь дом); задача дольше предела времени
(30 минут) останавливается с ошибкой.

## Объявления

`notifications/message`, `logger = "smartesp"`,
`data = {"type": "announce", "text": ..., "person": ...}` — как у `timers`:

- готово — «Клод закончил «<имя>»: <первая фраза ответа>.»; если Claude Code
  отклонил часть действий (`permission_denials` в ответе), добавляется «Часть
  действий Клоду не разрешили.», а задача — «готово с отказами»;
- ошибка — «Клод не справился с «<имя>»: <причина>.» (нет программы, ошибка
  входа, «не уложился в 30 минут» и т. п.).

Отменённая задача не объявляется. Пока клиента нет, объявления копятся.

## Как запускается Claude Code

Нужен Claude Code **2.1.328 или новее** (флаги `--restricted` и
`--permission-prompts`).

```
claude -p --output-format json --restricted --no-session-persistence --strict-mcp-config \
  --permission-mode acceptEdits --permission-prompts none --tools <CLAUDE_TASK_TOOLS>
```

Текст задачи идёт через stdin (не спутать с флагами), рабочая папка процесса —
выбранная разрешённая папка. Как это защищает:

- `--restricted` — файловые инструменты работают только в рабочей папке
  (прочитать или записать соседнюю папку, `~/.ssh` и т. п. нельзя); настройки
  пользователя и проекта (`~/.claude`, `.claude/settings*.json` — хуки, правила
  разрешений) не читаются; обход проверок запрещён; запись в настройки, git и
  конфигурацию инструментов (`.claude/`, `.git/`) — только с согласия человека;
- `--permission-prompts none` — спросить некого, поэтому всё, что потребовало бы
  согласия, сразу отклоняется;
- `--permission-mode acceptEdits` — правки внутри папки без вопросов;
- `--no-session-persistence` — разговор задачи (с содержимым прочитанных файлов)
  не сохраняется в `~/.claude/projects` и не появляется в `/resume` владельца;
- `--tools` — только перечисленные встроенные инструменты (по умолчанию без
  Bash и сети); `--strict-mcp-config` — без MCP-серверов из чужих настроек.

`--allowedTools`, `--add-dir` и `--dangerously-skip-permissions` не используются
никогда. Окружение процесса — только `PATH`, `HOME`, `USER`, `LOGNAME`, `SHELL`,
`TMPDIR`, `LANG`, `LC_*` и имена из `CLAUDE_TASK_ENV`; признаки родительской
сессии Claude Code (`CLAUDECODE`, `CLAUDE_CODE_*`) не передаются никогда, ключи
и токены (`ANTHROPIC_*`, `*TOKEN*`, `*SECRET*`, `*KEY*`) — только если названы в
`CLAUDE_TASK_ENV`. Отмена и предел времени останавливают всю группу процессов
Claude (TERM, через 5 с — KILL).

Папка задачи проверяется так: путь разворачивается через realpath (символьные
ссылки и «..»), и только потом сверяется со списком — ссылка или «..» наружу
дают отказ ещё до запуска Claude.

Проверено на настоящем Claude Code 2.1.328 (2026-11-19): файл в разрешённой
папке создаётся; прочитать и записать файл в соседней папке по абсолютному пути
нельзя; `.claude/settings.json` в разрешённой папке не создаётся.

## Настройки (переменные окружения)

| Переменная | Что | По умолчанию |
|---|---|---|
| `SMARTESP_CONNECTOR_DATA` | папка данных (обязательна) | — |
| `CLAUDE_TASK_FOLDERS` | разрешённые папки: `имя=путь;имя=путь`, первая — по умолчанию | нет — «Не настроены папки для задач Клода.» |
| `CLAUDE_TASK_TOOLS` | имена инструментов Claude Code через запятую (только имена: шаблоны вроде `Bash(...)` флаг `--tools` не понимает) | `Read,Edit,Write,Glob,Grep` (без Bash и сети) |
| `CLAUDE_TASK_TIMEOUT_MIN` | предел времени задачи, минуты | `30` |
| `CLAUDE_BIN` | путь к `claude` | из `PATH`, иначе `~/.local/bin/claude` |
| `CLAUDE_TASK_ENV` | имена переменных окружения через запятую, которые можно передать Claude (например `ANTHROPIC_API_KEY`) | ничего сверх белого списка |

**Не добавляйте в `CLAUDE_TASK_TOOLS` ничего сверх файловых инструментов.**
Добавить `Bash` — значит дать задаче, сказанной голосом, оболочку (любые команды)
внутри папки, без вопросов. `WebFetch`/`WebSearch` дают сеть; `Monitor`, `REPL`,
`CronCreate` и другие тоже могут запускать код. Коннектор допускает любой
инструмент сверх `Read,Edit,Write,Glob,Grep`, но пишет предупреждение в журнал.

Claude Code должен быть один раз авторизован владельцем (`claude` в терминале);
коннектор вход не делает.

## Остаточный риск (прочитать до включения)

- **Внутри разрешённой папки задача может перезаписать или очистить любой файл
  без вопросов** (Edit/Write). Удалять файлы и запускать команды она не может
  (нет Bash), но содержимое теряется: восстановить можно только через git, а
  незакоммиченные правки и файлы из `.gitignore` (`secrets.h`, `.env`) — никак.
- **Правки становятся кодом позже.** Если разрешить живой репозиторий SmartEsp,
  задача (сказанная, ослышанная или подсказанная текстом прочитанного файла)
  может изменить ядро, коннекторы или прошивку, а этот код запустится при
  следующем старте приложения, `uv run pytest` или прошивке платы.
- **Секреты внутри папки читаются** и могут попасть в ответ: он звучит вслух,
  пишется в журнал и уходит в Anthropic.
- **Цена и время:** ограничено только временем (30 минут), бюджета и предела
  шагов нет — худший случай 2 задачи × 30 минут работы агента.

Рекомендация: разрешённые папки — **отдельные рабочие копии** (`git worktree`
на своей ветке), которые владелец смотрит (`git diff`) перед слиянием; **никогда
не живой репозиторий SmartEsp**, из которого работает приложение.

## Данные

`<data>/<person>/tasks.json` — журнал последних 50 задач человека (`home` —
общие): текст, папка, состояние, время начала и конца, короткий итог или
причина ошибки, число отклонённых действий (`denials`; не ноль — «готово с
отказами», и итог кончается «Часть действий Клоду не разрешили.»). `<data>/<person>/output/<id>.md` — полный ответ Claude. Запись
атомарная (временный файл + rename). Задача, которая шла при остановке
коннектора, после перезапуска — «ошибка: прервана».

## Запуск и проверки

```
uv sync
SMARTESP_CONNECTOR_DATA=/tmp/claude-tasks CLAUDE_TASK_FOLDERS="sandbox=$HOME/claude-sandbox" uv run claude-tasks-mcp
uv run pytest -q
uv run ruff check && uv run ruff format --check
uv run pyright
```

Тесты не вызывают настоящий `claude`: инструменты проверяются через клиент-сессию
SDK в памяти с поддельным запуском, а запуск подпроцесса — с поддельной
программой `tests/fake_claude.py`.
