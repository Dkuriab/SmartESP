# claude-tasks-mcp — задачи для Клода

MCP-коннектор SmartESP: «Кузя, попроси Клода …» → фоновая задача Claude Code на
Mac в разрешённой папке. Статус — голосом; когда задача кончилась, коннектор
просит ядро сказать это вслух (уведомление `announce`). Работает по stdio.

## Инструменты

| Инструмент | Что делает | Пример ответа |
|---|---|---|
| `task_start(task, folder="")` | Запускает задачу в папке `folder` (имя из настроек, «имя/подпапка» или путь внутри разрешённой); пусто — первая папка. | «Передала Клоду: «почини тесты ядра». Скажу, когда закончит.» |
| `task_status(name="")` | Идёт / готово / ошибка / отменена и сколько времени; пусто — последняя задача. | «Задача «почини тесты ядра» идёт 5 минут.» |
| `tasks()` | Последние 5 задач. | «Задачи Клода: почини тесты — идёт 2 минуты; обнови readme — готово.» |
| `task_result(name="")` | Короткий итог: первые 2–3 предложения ответа Claude без разметки и кода. | «Починила test_x. Причина — опечатка.» |
| `task_cancel(name)` | Отменяет идущую задачу (процесс Claude останавливается). | «Задача «почини тесты» отменена.» |

Имя задачи — первые слова её текста («почини тесты ядра пожалуйста»); повтор —
с номером («задача 2»). Искать можно по части имени, без учёта регистра; если
подходит несколько — «Уточни: …».

Не больше 2 задач одновременно (на весь дом); задача дольше предела времени
(30 минут) останавливается с ошибкой.

## Объявления

`notifications/message`, `logger = "smartesp"`,
`data = {"type": "announce", "text": ..., "person": ...}` — как у `timers`:

- готово — «Клод закончил «<имя>»: <первая фраза ответа>.»;
- ошибка — «Клод не справился с «<имя>»: <причина>.» (нет программы, ошибка
  входа, «не уложился в 30 минут» и т. п.).

Отменённая задача не объявляется. Пока клиента нет, объявления копятся.

## Как запускается Claude Code

```
claude -p --output-format json --permission-mode acceptEdits \
  --tools=<CLAUDE_TASK_TOOLS> --allowedTools=<CLAUDE_TASK_TOOLS> --strict-mcp-config
```

Текст задачи идёт через stdin (не спутать с флагами), рабочая папка процесса —
выбранная разрешённая папка. `--tools` ограничивает набор встроенных
инструментов, `--allowedTools` разрешает их без вопросов, `--strict-mcp-config`
не подключает MCP-серверы из чужих настроек. `--dangerously-skip-permissions`
не используется никогда. Отмена и предел времени останавливают всю группу
процессов Claude (TERM, через 5 с — KILL).

Папка проверяется так: путь разворачивается через realpath (символьные ссылки и
«..»), и только потом сверяется со списком — ссылка или «..» наружу дают отказ.

## Настройки (переменные окружения)

| Переменная | Что | По умолчанию |
|---|---|---|
| `SMARTESP_CONNECTOR_DATA` | папка данных (обязательна) | — |
| `CLAUDE_TASK_FOLDERS` | разрешённые папки: `имя=путь;имя=путь`, первая — по умолчанию | нет — «Не настроены папки для задач Клода.» |
| `CLAUDE_TASK_TOOLS` | инструменты Claude Code через запятую | `Read,Edit,Write,Glob,Grep` (без Bash и сети) |
| `CLAUDE_TASK_TIMEOUT_MIN` | предел времени задачи, минуты | `30` |
| `CLAUDE_BIN` | путь к `claude` | из `PATH`, иначе `~/.local/bin/claude` |

Claude Code должен быть один раз авторизован владельцем (`claude` в терминале);
коннектор вход не делает.

## Данные

`<data>/<person>/tasks.json` — журнал последних 50 задач человека (`home` —
общие): текст, папка, состояние, время начала и конца, короткий итог или
причина ошибки. `<data>/<person>/output/<id>.md` — полный ответ Claude. Запись
атомарная (временный файл + rename). Задача, которая шла при остановке
коннектора, после перезапуска — «ошибка: прервана».

## Запуск и проверки

```
uv sync
SMARTESP_CONNECTOR_DATA=/tmp/claude-tasks CLAUDE_TASK_FOLDERS="smartesp=$HOME/SmartEsp" uv run claude-tasks-mcp
uv run pytest -q
uv run ruff check && uv run ruff format --check
uv run pyright
```

Тесты не вызывают настоящий `claude`: инструменты проверяются через клиент-сессию
SDK в памяти с поддельным запуском, а запуск подпроцесса — с поддельной
программой `tests/fake_claude.py`.
