# weather — погода (Open-Meteo)

MCP-коннектор SmartESP. Короткие фразы для озвучки; данные — Open-Meteo
(бесплатно, без ключа, из России доступен без VPN).

## Инструменты

- `weather_now()` — состояние, температура, как ощущается, осадки, ветер.
- `weather_forecast(day="сегодня")` — мин/макс, осадки и их вероятность, ветер.
  День: сегодня, завтра, послезавтра, день недели («в пятницу» — ближайший,
  включая сегодня), «в выходные». Прогноз — на 7 дней вперёд.

Сеть или сервис недоступны, место не найдено — ошибка инструмента
«Не получилось узнать погоду.» Место не задано — «Место не задано в настройках погоды.»

## Переменные окружения

- `WEATHER_PLACE` — «Город» или «Город, Страна» (название или код: «Кировск, Беларусь»).
  Геокодинг Open-Meteo берёт 10 вариантов: названная страна, иначе Россия, среди них
  самый людный. Найденное место пишется в журнал (stderr); в ответе называется,
  только если отличается от заданного («Место: Санкт-Петербург. …»). Результат
  запоминается в памяти на время работы процесса.
- `WEATHER_LAT`, `WEATHER_LON` — координаты (имеют приоритет, геокодинг не нужен).

`SMARTESP_CONNECTOR_DATA` не нужна: коннектор ничего не хранит на диске.
`_meta.person` не используется.

## Запуск и проверки

```
uv sync
uv run weather-mcp       # stdio
uv run pytest -q         # без сети (httpx.MockTransport)
WEATHER_LIVE=1 uv run pytest -q   # + один живой запрос к Open-Meteo
uv run ruff check && uv run ruff format --check
uv run pyright
```
