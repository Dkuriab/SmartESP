# Коннектор «Колонки» (speakers)

Скиллы ассистента про колонки дома:
- `speakers_list` — какие колонки есть, в сети ли, громкость;
- `speaker_volume(percent?, change?, speaker?)` — узнать или изменить общую громкость колонки (голос
  Кузи и музыка на ней) («сделай погромче» — `change: +20`, «громкость на кухне 30» — `speaker: Кухня,
  percent: 30`). Без названия — колонка, с которой сейчас говорят (`_meta.device` вызова от ядра),
  иначе единственная в сети. Ненулевой `change` важнее `percent` (модели шлют `percent: 0` рядом со
  сдвигом — это не «выключи»); отрицательный `percent` — ошибка, а не тишина. Громкость самой
  музыки — инструмент коннектора music, описание отсылает к нему.

Коннектор ходит в API ядра: в `smartesp.json` объявлено `"core_api": true`, и ядро передаёт ему
`SMARTESP_URL` и `SMARTESP_TOKEN`. Громкость хранится в настройках ядра (`devices.<MAC>.volume`), ядро
сразу шлёт её колонке и повторяет при каждом подключении.

uv run pytest -q && uv run ruff check && uv run pyright
