# mac_media — звук и музыка на Mac

MCP-коннектор SmartESP: медиа-клавиши, громкость, устройство вывода и музыка
из своей медиатеки. Только узкие инструменты — произвольный AppleScript
коннектор не выполняет: скрипты фиксированные, а данные человека (поисковый
запрос, громкость) передаются аргументами `on run argv`, не подстановкой в текст.

## Инструменты

- `media_play_pause()`, `media_next()`, `media_previous()` — системные
  медиа-клавиши (событие NX «system defined», как у клавиатуры Mac): работают с
  любым плеером. Нужно разрешение «Универсальный доступ» для приложения, которое
  запускает ядро; без него — честный ответ, где его дать (проверка без запроса:
  `CGPreflightPostEventAccess`).
- `media_now_playing()` — что играет: «Музыка» или Spotify через их AppleScript
  (только запущенные; спрашиваются лишь название, исполнитель и состояние).
  Ничего — «Не вижу, что сейчас играет.» Системное «Сейчас играет»
  (MediaRemote) — закрытый фреймворк, на новых macOS ненадёжен, не используется.
- `volume_get()`, `volume_set(percent)`, `volume_change(delta)` — громкость выхода
  (`osascript`, Standard Additions): целое 0–100, изменение −100…100 с упором в
  границы. Устройство без регулировки — честный ответ.
- `output_devices()`, `output_set(name)` — список устройств вывода (динамики,
  Bluetooth, AirPlay) и переключение через CoreAudio (ctypes). Имя — без
  регистра и «ё», можно часть; несколько подходящих — «Уточни: …».
- `music_play(query)` — поиск в своей медиатеке «Музыки» (`search library
  playlist 1`) и запуск первого совпадения; не нашлось и установлен Spotify —
  поиск `spotify:search:…` в Spotify.

Отказ macOS в разрешении «Автоматизация» (ошибка −1743) — ответ «Нет разрешения
управлять приложением «Музыка». Разреши в Настройках → Конфиденциальность →
Автоматизация.» Пока macOS показывает запрос, вызов ждёт до 15 секунд, потом
отвечает, что приложение не отвечает.

## Данные

Коннектор ничего не хранит и не ходит в сеть: `SMARTESP_CONNECTOR_DATA` не
нужна. `_meta.person` не используется.

## Устройство

- `system.py` — договор `MediaSystem` (всё, что трогает ОС) и его ошибки.
- `media.py` — логика инструментов и русские ответы; работает только с договором.
- `mac.py` — настоящая система: `osascript.py` + `scripts.py` (AppleScript),
  `coreaudio.py` (устройства), `keys.py` (медиа-клавиши, pyobjc).
- `server.py` — инструменты MCP и запуск по stdio.

Тесты идут с подделкой системы: громкость, клавиши и устройства не меняются,
плееры не трогаются (настоящий `osascript` запускается только со скриптом-эхом).
Живая проверка — владельцем: каждый инструмент на этом Mac, первый раз macOS
спросит разрешения.

## Запуск и проверки

```
uv sync
uv run mac-media-mcp     # stdio
uv run pytest -q
uv run ruff check && uv run ruff format --check
uv run pyright
```
