# calc — точный счёт и кухонные единицы

MCP-коннектор SmartESP. Маленькие модели плохо считают в уме, поэтому
арифметику и перевод единиц делает этот коннектор — точно.

## Инструменты

- `calculate(expression)` — выражение с `+ - * / ** % ( )`, функциями
  `sqrt round abs min max`, десятичной запятой или точкой. Разбор через `ast`
  с белым списком (не `eval`), длина до 200 символов, степень не больше 100.
  Дробь с запятой понимается вне скобок функций; внутри скобок функции запятая —
  разделитель аргументов (`max(1,5)`), дробь там пишется точкой.
  Целые и дроби считаются точно (3**60 — все цифры), округление школьное (round(2,5 половина вверх): 2.5 даёт 3). Ответ: до 4 знаков после запятой, без хвостовых нулей, запятая («50,5»).
- `convert(value, from_unit, to_unit, product="")` — масса (мг, г, кг, фунт,
  унция), объём (мл, л, ч. л. = 5 мл, ст. л. = 15 мл, стакан = 250 мл),
  температура (°C, °F). Масса ↔ объём — только с продуктом из таблицы
  плотностей (мука, сахар, соль, рис, гречка, молоко, вода, масло растительное,
  масло сливочное, мёд, крупа манная); без продукта или с незнакомым — отказ.
  Единицы принимаются в русских формах и сокращениях («грамм», «граммов»,
  «ст.л.», «столовая ложка»).
- `split(total, parts, unit="")` — поровну: «500 г на 10 — по 50 г».

Ошибки (деление на ноль, непонятное выражение, незнакомая единица) приходят как
ошибка инструмента с коротким русским текстом.

## Данные

Коннектор ничего не хранит и не ходит в сеть, поэтому папка
`SMARTESP_CONNECTOR_DATA` ему не нужна: без этой переменной он запускается
нормально (правило «нет переменной — ошибка запуска» — для коннекторов, которые
хранят данные). `_meta.person` не используется.

## Запуск и проверки

```
uv sync
uv run calc-mcp          # stdio
uv run pytest -q
uv run ruff check && uv run ruff format --check
uv run pyright
```
