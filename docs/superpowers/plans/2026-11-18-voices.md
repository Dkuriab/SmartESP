# Голоса Silero и Vosk — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** в ядре появляются голоса `silero` (xenia, baya, kseniya) и `vosk`
(female_0..2). Голос по умолчанию — Silero xenia. Голоса скачиваются сами, у
всех есть стиль `quiet`.

**Architecture:**
- Новые реализации договора `TextToSpeech` лежат в `core/smartesp/tts/` и
  регистрируются в `TTS_KINDS` в `main.py`.
- Каталог и скачивание голосов — там же, в `tts/`. Тип каталога `VoiceInfo`
  уже лежит в `contracts`: позже его отдаёт API.
- При старте `main.py` спрашивает у `tts.ensure_voice`, какой голос
  использовать: скачанный нужный, после скачивания — нужный, а при сбое — любой
  уже скачанный.

Это промежуточная версия раздела 5.1 дизайна. Фоновое скачивание с подменой на
лету делает план «ядро для приложения», потому что ему нужен модуль `control`.

**Tech Stack:**
- Python 3.12, uv;
- новые зависимости: `torch` (Silero через `torch.package`), `vosk-tts`,
  `num2words`;
- скачивание через `httpx`, ресемплинг через `soxr`.

**Spec:** `docs/superpowers/specs/2026-11-18-app-voices-design.md`, раздел 5.1
и раздел 8. Общие правила — `core/CLAUDE.md`.

## Global Constraints

- Все команды запускаются из `core/`.
- Перед каждым коммитом зелёные:
  - `uv run pytest`;
  - `uv run ruff check`;
  - `uv run ruff format --check`;
  - `uv run pyright`.
- Зависимости — точные версии в `pyproject.toml` через `==`, плюс `uv.lock`:
  - `torch==2.15.0` (уже стоит в `uv.lock` через mlx-whisper, теперь прямая
    зависимость);
  - `vosk-tts==0.3.61`;
  - `num2words==0.5.14`.

  Совместимость проверена `uv pip compile`.
- Модули импортируют только `smartesp.contracts`. `main.py` — только связка.
- Размеры: файл ≤ 300 строк, функция ≤ 50 строк, сложность ≤ 10.
- Имена — по-английски, комментарии и docstring'и — по-русски.
- Выход любого TTS — PCM 16 кГц s16le моно, ресемплинг через
  `tts/resample.py:resample_s16`.
- Тесты с настоящими моделями помечаются `@pytest.mark.models` и пропускаются,
  если голос не скачан (`pytest.skip` с понятной причиной).
- Папка данных: `SMARTESP_HOME`, иначе `~/SmartEsp`. Голоса лежат:
  - Piper — `voices/<voice>.onnx` и `.onnx.json`, путь прежний;
  - Silero — `voices/silero/v5_ru.pt`;
  - Vosk — `voices/vosk/vosk-model-tts-ru-0.9-multi/`.

  - Piper:
    `https://huggingface.co/rhasspy/piper-voices/resolve/main/<lang>/<locale>/<name>/<quality>/<voice>.onnx`
    и `.onnx.json`, где голос — `<locale>-<name>-<quality>`, а `lang` —
    часть `locale` до `_`;
  - Silero: `https://models.silero.ai/models/tts/ru/v5_ru.pt`;
  - Vosk:
    `https://alphacephei.com/vosk/models/vosk-model-tts-ru-0.9-multi.zip`.
- Лицензия Silero — CC BY-NC-SA, только некоммерческое использование.
  Написать это в README рядом с голосами.
- Коммиты — по-английски и заканчиваются строкой
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Пушим сразу в
  `main`.

**Проверено вручную (spike) — на это можно опираться:**
- Silero v5 загружается так:
  `torch.package.PackageImporter(path).load_pickle("tts_models", "model")`,
  затем `model.to(torch.device("cpu"))`.
- Синтез: `model.apply_tts(text=…, speaker="xenia", sample_rate=24000)` →
  `torch.float32` в диапазоне [-1, 1].
  `apply_tts(ssml_text="<speak><prosody rate=\"slow\">…</prosody></speak>", …)`
  работает и даёт звук длиннее.
- Голоса Silero: `aidar, baya, kseniya, eugene, xenia`. Мы берём только
  женские.
- Vosk: `from vosk_tts import Model, Synth`, затем
  `Synth(Model(model_path=dir)).synth_audio(text, speaker_id=N, speech_rate=R)`
  → `np.int16` на частоте `config.json["audio"]["sample_rate"]` (22050).
- Голоса Vosk берутся из `config.json["speaker_id_map"]`:
  `female_0: 0, female_1: 1, female_2: 2, male_0: 3, male_1: 4`.
- Цифры: Silero их молча выкидывает, Vosk падает с `KeyError: '5'`.

## Review Focus

1. **Латиница, эмодзи и символы в ответе** («Wi-Fi», «25 °C», «№ 3», «😀»):
   Vosk не падает, а неозвучиваемое предложение тихо пропускается с записью в
   журнал. Тесты — в задачах 1 и 4.
2. **Предложение, от которого после чистки ничего не осталось** («…», «😀»):
   синтез не вызывается, звук пустой, без исключения. Тесты — в задачах 3
   и 4.
3. **Скачивание оборвалось, сервер ответил 404 или архив битый:** на диске нет
   ни половинки голоса, ни папки, которая считается скачанной. Следующий
   старт качает заново. Тест — в задаче 2.
4. **Странные числа** (`10**40`, `2,5`, `-3`, `8:05`, `50%`, `2024`):
   переводятся в слова или по одной цифре, без исключений. Тест — в задаче 1.
5. **Две колонки синтезируют одновременно:** модель защищена замком, оба
   ответа приходят целыми. Тест с моделями — в задаче 3.
