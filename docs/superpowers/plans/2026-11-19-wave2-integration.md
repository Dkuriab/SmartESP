# Вторая волна: подключение коннекторов, честность, пульт — план

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** коннекторы работают в живом ядре и видны в приложении; Кузя не выдумывает; Telegram говорит с ядром; файл играется на колонке; приложение — пульт ядра.

**Architecture:** всё уже написано по частям (`core/smartesp/tools/`, `network/tool_loop.py`, `connectors/*`, `clients/telegram/`); эта волна — связка, общие механизмы ядра и интерфейс. Задачи W1–W5, W7, W8 — по очереди в `main`; W6 (Swift) — параллельно в своей ветке.

**Specs:** `docs/superpowers/specs/2026-11-19-mcp-hub-design.md` (4.2, 4.5), `2026-11-19-honesty-weather-design.md`, `2026-11-19-food-telegram-design.md` (2.3), решения владельца в разговоре (пульт, файл на колонке) — записаны в задачах ниже.

## Global Constraints

- Правила `CLAUDE.md`, `core/CLAUDE.md`, `ui/CLAUDE.md`, `app/CLAUDE.md`. **В ядре и приложении нет кода под конкретную функцию** (еда, погода, музыка) — только общие механизмы (память владельца `features-outside-core-app`).
- Выполнение в `main` (кроме W6), коммиты на английском, `Co-Authored-By` по модели исполнителя; не пушить — пушит контроллер.
- Тесты ядра без железа и моделей, `~/SmartEsp` не трогают. Живые проверки — правила владельца: не занимать порт 8765, если занят; временная `SMARTESP_HOME`; `cmp` конфигов владельца; ничего не оставлять запущенным; не править настройки владельца; не отвечать на системные запросы macOS.
- `orchestrator.py` 299/300 строк, `wiring.py` ~275 — новое выносить в отдельные файлы.
- Ошибки инструментов: убирать английскую приставку SDK «Error executing tool <name>: » перед тем, как отдать текст модели.

---

### W1: коннекторы в живом ядре

- Раздел настроек `connectors: list[{id, name, command, args, env, enabled}]`; по умолчанию пять наших — `notes`, `calc`, `timers`, `weather`, `food`: `command: uv`, `args: [run, --project, <repo>/connectors/<id>, <id>-mcp]`, где `<repo>` — корень репозитория, вычисленный от расположения ядра (в настройках по умолчанию — подставленный путь). `weather` без места: `env: {WEATHER_PLACE: ""}` — честный ответ «место не задано», пока владелец не впишет.
- `McpHub` в связке: старт при запуске ядра (не задерживает готовность голоса дольше, чем сейчас: коннекторы стартуют в фоне), правка раздела `connectors` — `hub.apply` на лету + пересборка сети исполнителей с новым `toolbox.specs()` тем же путём, что правка исполнителей; `on_announce(text, person, connector)` → `Announcer.say(device, text, source=connector)`, колонка — последняя активная; остановка — `hub.aclose()` в пределах честной остановки, до закрытия колонок.
- `build_network(..., toolbox=hub)` в `kinds.py`/связке.
- `/status` — состояния коннекторов; `GET /api/v1/connectors` — список с состоянием, инструментами, ошибкой.
- `conversation/sentences.py`: перенос строки всегда заканчивает предложение (короткая фраза перед инструментом звучит сразу).
- Хаб: снять приставку «Error executing tool …: ».
- Тесты: связка с поддельными коннекторами (маленький тестовый MCP-сервер, как в `tests/tools/`); правка `connectors` на лету; announce → `say`; остановка без сирот.

### W2: честные ответы и время

- Промпт по умолчанию дополняется правилом из `2026-11-19-honesty-weather-design.md` (п. 1); прежний промпт по умолчанию — в `_LEGACY_PROMPTS` (переход как раньше), свой промпт владельца не трогается.
- Обработчик фразы `clock` в реестре (как `whisper_detect`), включён по умолчанию: пометка «[время] среда, 19 ноября 2026, 21:40, вечер» (местное время, русские названия, части суток: ночь 0–5, утро 6–11, день 12–17, вечер 18–23).
- Строка правил сети при наличии инструментов: «Для фактов пользуйся инструментами; если нужного инструмента нет — скажи, что нет доступа.»
- Тесты: пометка `clock` с поддельными часами; миграция промпта; правило в промпте при наличии инструментов.

### W3: живая подсветка и панель коннекторов

- Ядро шлёт события хода: `executor_active {turn_id, executor, state: thinking|speaking|done}`, `tool_call {turn_id, connector, tool, state: started|finished, ok}`; `turn_finished` получает список вызовов инструментов `tools: [{connector, tool, ok}]`.
- `/status` — модели, загруженные в Ollama (`ollama ps` через клиент), с признаком «в памяти».
- Интерфейс: коннекторы — узлы на схеме (колонка справа от исполнителей); работающие сейчас узлы пульсируют с подписью («думает…», «говорит», «calc: считает»), отдельно от подсветки пути выбранного хода; панель коннектора: состояние, инструменты, ошибка, вкл/выкл (PATCH `connectors`); в ленте — какие инструменты вызывались; у исполнителей — «в памяти».
- Тесты ядра на события; тесты интерфейса (reducer, схема, панель); скриншот живого интерфейса в отчёт.

### W4: ход через API (Telegram)

- `POST /api/v1/ask` и `POST /api/v1/ask/voice` — ровно по договору `clients/telegram/README.md` (разделы про `/ask`); ход идёт обычным путём (обработчики, сеть, инструменты, история), без звука; в ленте источник «Telegram» (`origin: "api"`, `source`).
- Голос: OGG/Opus → ffmpeg (`/opt/homebrew/bin/ffmpeg`, найти через PATH) → 16 кГц PCM → тот же STT.
- Тесты API с подделками; живая проверка бота — по README бота (токен — у владельца, не делаем).

### W5: файл на колонке

- `POST /api/v1/devices/{id}/play` (multipart, файл до 50 МБ; MP3/WAV/OGG/M4A) → ffmpeg → 16 кГц моно PCM → воспроизведение ходом ядра через `DevicePort.announce` (прошивка сыграет «внимание» перед файлом — допустимо) с ответом `{delivery}`; колонка занята — 409; колонка v2 — 409 с понятным текстом.
- В интерфейсе на панели колонки — кнопка «Проиграть файл…».
- Тесты API и интерфейса с подделками.

### W6 (параллельно, ветка `feature/app-control`): пульт в Mac-приложении — родная часть

- Меню и окно-заглушка (когда ядро не работает): «Запустить ядро», «Остановить ядро»; для чужого ядра — «Взять управление» (SIGTERM процессу из `run/core.json` → дождаться остановки ≤ 15 с → запустить своё); «Запустить Ollama», если Ollama не отвечает (`open -a Ollama`, иначе `ollama serve` в фоне).
- В окне (заглушка без ядра) — состояние и кнопки родными элементами.
- Мост WKWebView → приложение для интерфейса: `openDataFolder`, `openConfig`, `revealLog` (сообщения `webkit.messageHandlers.smartesp`), вызываются из вкладки «Ядро» (W7).
- Тесты в `SmartEspKit` (swift-testing): логика «взять управление», состояния меню; сборка `app/build.sh`.

### W7: вкладка «Ядро» в интерфейсе

- Ядро: `GET /api/v1/core` — версия, время работы, порт, папка данных; `POST /api/v1/core/restart` (есть ли уже — проверить), `POST /api/v1/core/stop`; журнал — WebSocket `/api/v1/logs` (последние 500 строк + новые, с сокрытием токена), уровни.
- Интерфейс: вкладка «Ядро»: состояние, перезапуск/остановка, модели в памяти с «Выгрузить», живой журнал с фильтром «ошибки/всё», кнопки моста W6 («Папка данных», «config.yaml», «Журнал в Finder») — видны, только если мост есть.
- Тесты ядра и интерфейса.

### W8: живая проверка

- Ядро на свободном порту, временная `SMARTESP_HOME`, Ollama как есть: «добавь молоко в покупки» → «что в покупках?»; «раздели 500 г на 10 порций»; «поставь таймер на 1 минуту» → через минуту объявление на поддельной колонке; «какая погода?» без места → честный ответ; «который час?» — по пометке `clock`; «включи свет на кухне» → «нет доступа»; `/api/v1/ask` текстом. Задержки, скриншоты, чистота после проверки — в отчёт.
