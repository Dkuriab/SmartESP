# Колонка без зашитых адресов: поиск ядра и настройка Wi-Fi с телефона

Дата: 2026-11-26. Прошивка 0.8.0. Одобрено владельцем в разговоре.

## Зачем

Сейчас в `secrets.h` зашиты Wi-Fi и IP Mac. Сменился IP Mac или сеть — колонку надо
перепрошивать. Владелец хочет, чтобы в прошивке не было зашито ничего: колонка сама
находит ядро в сети, а Wi-Fi ей задают с телефона.

## Цели

- Ядро объявляет себя в локальной сети (Bonjour/mDNS); колонка находит его сама и
  переподключается, если IP Mac сменился.
- Колонка видна в сети как `kuzya-xxxx.local` (xxxx — 4 последних знака MAC).
- Нет сохранённой сети или 2 минуты не удаётся к ней подключиться — колонка
  поднимает открытую точку доступа `Kuzya-xxxx` со страницей настройки (captive portal):
  список найденных сетей, пароль, «Сохранить». Сеть хранится во флеше колонки (NVS).
- `secrets.h` больше не нужен: из прошивки уходят `WIFI_*` и `SERVER_*`.

## Не цели

- Настройка через Bluetooth (сотни КБ прошивки и приложение на телефоне).
- Подтверждение новой колонки в приложении (ядро и сейчас принимает любую).
- Изменение протокола колонка ↔ ядро (остаётся 5) и разметки флеша.

## Анти-цели

- Колонка после обновления по воздуху с 0.7.0 на 0.8.0 выпала из сети и требует
  телефона, хотя могла взять уже известную сеть.
- `loop()` блокируется поиском mDNS, сканированием сетей или веб-страницей.
- Колонка уходит к чужому ядру, когда «своё» на месте.

## Подход (выбран)

Колонка остаётся клиентом WebSocket, меняется только то, **как она узнаёт адрес**:
ядро объявляет службу `_smartesp._tcp` (порт из настроек ядра; TXT: `id` — постоянный
id ядра, `path=/device`, `version`), колонка ищет её запросом mDNS.

Отвергнуто: ядро ищет колонки и само к ним подключается (переворот протокола и сервер
на колонке — много работы без выгоды); BLE-настройка (см. не цели).

## Ядро

- Новый модуль объявления в сети (имя — на усмотрение исполнителя, например
  `smartesp/discovery/`), библиотека `zeroconf` (async), версия через `==` в
  `pyproject.toml`. Объявляет при старте, снимает объявление при остановке.
- Постоянный id ядра — создаётся один раз и хранится в папке данных ядра (`~/SmartEsp`).
- Ошибка объявления (нет сети, занято имя) — в журнал, ядро работает дальше.
- Тесты — без настоящей сети (подделка регистратора).

## Прошивка

Новые модули (по правилам `CLAUDE.md`: модули друг друга не знают, связь — в `.ino`):

- **Настройки сети** — хранение сети (SSID, пароль) и id выбранного ядра в NVS.
- **Wi-Fi и точка настройки** — развитие `wifi_link`: станция по сохранённой сети;
  нет сети или 2 мин без подключения — режим AP+STA, точка `Kuzya-xxxx`, `DNSServer`
  (все имена → колонка, чтобы телефон сам открыл страницу) и `WebServer` со страницей.
  Пока точка открыта, колонка продолжает пробовать сохранённую сеть; подключилась —
  точку закрывает. Страница — на русском, без внешних ресурсов.
- **Поиск ядра** — mDNS (`ESPmDNS`) в своей задаче FreeRTOS (запрос блокирует до секунд):
  ищет `_smartesp._tcp`, отдаёт host/port. Несколько ядер — то, к которому колонка
  подключалась в прошлый раз (id из TXT); его нет — первое найденное. Повторный поиск —
  когда связи с ядром нет (с паузами, как переподключение Wi-Fi).
- `server_link`, `updater`, `stream_player` получают адрес ядра не в `begin`, а по ходу
  работы (функция вида `setServer(host, port)`); `.ino` передаёт им результат поиска.
- Имя хоста `kuzya-xxxx` через mDNS.

**Переход с 0.7.0.** Библиотека Wi-Fi ESP32 сама хранит последнюю сеть во флеше. Если
своей сохранённой сети нет, 0.8.0 сначала пробует сеть, сохранённую библиотекой, и при
успехе записывает её как свою. Только если её нет или она не работает — точка настройки.
Проверить на плате; худший случай — один раз настроить с телефона.

`secrets.h` и `secrets.example.h` из прошивки уходят; правило «секреты — в `secrets.h`»
в корневом `CLAUDE.md` остаётся для будущих секретов — поправить текст при необходимости.
README: как настроить колонку с телефона.

## Проверка

- Ядро: тесты, ruff, pyright.
- Прошивка: сборка; хост-тесты для чистой логики (выбор ядра из найденных, разбор формы).
- На плате (владелец): чистая колонка → точка `Kuzya-xxxx` → телефон → сеть → колонка
  нашла ядро; смена IP Mac → колонка нашла заново; обновление 0.7.0 → 0.8.0 по воздуху
  — осталась в сети; неверный пароль → через 2 мин снова точка.

## На усмотрение исполнителя

Имена модулей и функций, вид страницы, точные паузы повторного поиска, формат TXT
сверх `id`/`path`, как показать в приложении, что колонка нашла ядро сама (не обязательно).
