# Облачные модели по ключу (OpenRouter) — дизайн

Дата: 2026-11-21. Владелец: «добавь возможность подключать модели по ключу удалённые, не
только локальные»; сервис — OpenRouter (облачные модели Ollama платные).

## Что и зачем

Любой исполнитель (диспетчер, «большая» модель, новый) может работать не в Ollama на Mac,
а в облаке через OpenRouter: сотни моделей по одному ключу, OpenAI-совместимый API.

## Решения

- **Подходы.** (1) свой вид исполнителя `cloud` с OpenAI-совместимым API — выбран: один
  код на OpenRouter и любой совместимый сервис; (2) облачные модели Ollama — платные,
  владелец отказался; (3) отдельный коннектор MCP — не подходит: исполнитель — часть ядра
  (сеть исполнителей, передачи, инструменты), а не возможность.
- **Настройки.** Раздел `cloud: {name: OpenRouter, base_url: https://openrouter.ai/api/v1,
  api_key: ""}` — один облачный сервис (YAGNI); другой совместимый сервис — правкой
  `base_url`/`name` в `config.yaml`. Исполнитель: `kind: cloud`, `model` — id модели сервиса
  (`google/gemini-2.5-flash`).
- **Ключ.** Хранится только в `~/SmartEsp/config.yaml` (вне git). `GET /config` отдаёт
  вместо него «•••»; «•••» в правке — «не менять». Через API меняется только
  `cloud.api_key`: `base_url` и `name` — только руками в `config.yaml`, иначе токен API
  позволил бы увести ключ на чужой сервер. Ключ не пишется в журнал.
- **Исполнитель.** Поток `chat/completions` (SSE): текст по кускам, вызовы инструментов
  собираются из кусков и отдаются в конце. Рассуждение — `reasoning.effort`
  (off → `none`, иначе уровень). Ошибки — понятным текстом (401 ключ, 402 нет денег,
  404 модели нет, 429 предел, нет сети). Прогрев — только проверка, что ключ задан.
- **Умение инструментов.** Модели в сети узнаются по ключу `@cloud/<id>` (в Ollama `@` в
  именах не бывает): для них возможности — «инструменты есть», без запроса в Ollama.
- **Список моделей.** `GET /api/v1/cloud/models` — ядро берёт `{base_url}/models`
  (кэш 10 мин): id, имя, умеет ли инструменты, цена за 1 млн токенов.
- **Интерфейс.** В настройках диспетчера/исполнителя — «Где работает: на Mac (Ollama) /
  OpenRouter»; для облака — модель из списка (с поиском) и цена. В настройках ядра — ключ
  OpenRouter (скрытое поле) и предупреждение: текст разговоров уходит в облако.

## Не делаем

Несколько облачных сервисов одновременно, автоматический откат на локальную модель при
обрыве сети (ошибка звучит, как при недоступной Ollama), учёт расходов.
