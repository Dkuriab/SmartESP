# LM Studio рядом с Ollama

Дата: 2026-11-26. Одобрено владельцем в разговоре.

## Зачем

Владелец хочет запускать локальные модели и через LM Studio, а не только через Ollama.
На его Mac стоит LM Studio Bionic (отдельное приложение LM Studio); подключаемся к
локальному серверу LM Studio с OpenAI-совместимым API (по умолчанию `http://localhost:1234`).

## Цели

- Третий вид исполнителя `lmstudio` рядом с `ollama` и `cloud`: в «Сети моделей» у
  каждого исполнителя свой вид (например, Кузя — LM Studio, помощник — Ollama).
- Раздел настроек `lmstudio`: адрес сервера (по умолчанию `http://localhost:1234`) и
  необязательный ключ. Адрес меняется и из приложения (сервер может быть на другом Mac);
  ключ API отдаёт как «•••», как у облака.
- Список моделей LM Studio в выборе модели: загружена ли, умеет ли инструменты.
- Ход — потоком, с инструментами, как у облачного исполнителя (тот же OpenAI-формат).
- Прогрев при старте/смене модели, как у Ollama (LM Studio сам загружает модель по запросу).
- Понятные ошибки: сервер LM Studio не запущен, модели нет, модель не умеет инструменты.

## Не цели

- Скачивание моделей LM Studio из нашего приложения (качают в самом LM Studio).
- Управление самим LM Studio (запуск приложения или сервера).

## Анти-цели

- Сломать работу исполнителей `ollama` и `cloud` и их настройки.
- Утечка ключа облака: адрес облака по-прежнему меняется только в `config.yaml`.

## Подход (выбран)

Переиспользовать OpenAI-совместимый клиент облачного исполнителя (`executors/cloud_executor.py`)
— вынести общее, а не копировать. Список моделей и их состояние — из REST API LM Studio
(`/api/v1/models` или `/api/v0/models` — что отвечает; запасной путь — `/v1/models`).
Имя модели в сети — с приставкой вида (как `@cloud/…`), чтобы возможности не спрашивались
у Ollama.

Отвергнуто: «LM Studio как облако с другим адресом» — у облака один раздел на всех,
адрес закрыт от API, и нельзя держать облако и LM Studio одновременно.

## Проверка

Тесты на подделке сервера LM Studio (как у облака), ruff, pyright, тесты интерфейса.
С настоящим LM Studio проверяет владелец: выбрать вид «LM Studio», модель, задать вопрос
голосом, вызвать навык.

## На усмотрение исполнителя

Как передавать рассуждение (reasoning) и время удержания модели (ttl), как прогревать,
вид полей в интерфейсе, версия конфигурации и перенос настроек.
