# Обновление колонок по воздуху: прошивка и модель слова — дизайн

Дата: 2026-11-22. Просьба владельца: «сделай так, чтобы можно было прошивать ESP удалённо или
хотя бы обновлять модель для распознавания слова». Колонки стоят по дому; плата подключена к
другому компьютеру — прошивка по USB неудобна, а модель слова теперь обучается часто.

## Решения

- **Подходы.** (1) колонка сама скачивает файл у ядра по HTTP по команде через WebSocket —
  выбрано: ядро уже знает колонки, связь есть, адрес ядра колонка знает; (2) ArduinoOTA (push с
  ноутбука по mDNS) — нужен Arduino IDE и сеть с ноутбука, из приложения не сделать; (3) модель по
  WebSocket кусками — только модель, прошивку так не передать (3 МБ через очередь звука).
- **Разметка памяти уже подходит** (`esp_sr_16`): две половины под прошивку `app0`/`app1` по 3 МБ
  (новая пишется в свободную, загрузка переключается только после полной записи и проверки — при
  обрыве колонка остаётся на старой) и свободный раздел `spiffs` 6 МБ — в нём LittleFS для модели.
- **Протокол 4.** Колонка с прошивкой 0.5.0 говорит в `hello` `protocol: 4` — ядро шлёт ей
  `update` только тогда. Команда:
  `{"type":"update","what":"firmware"|"model","path":"/device/files/<токен>","size":N,"sha256":"…"}`,
  для модели ещё `cutoff`, `window`, `arena`, `word`. Колонка качает
  `http://<SERVER_HOST>:<SERVER_PORT><path>`, считает SHA-256 на ходу, шлёт
  `{"type":"update_status","what",…,"state":"progress"|"done"|"failed","done","total","error"}`
  (ход — раз в ~0,5 с), после успеха перезагружается.
- **Файлы для колонки** — `GET /device/files/<токен>` без токена API (у колонки его нет): токен
  случайный, одноразовый на обновление, живёт 15 минут.
- **Модель** хранится в LittleFS: `/wakeword.bin` и `/wakeword.cfg` (порог, окно, арена, слово);
  запись — во временный файл, проверка SHA-256, затем переименование. При загрузке колонка берёт
  сохранённую модель, а если её нет или она не запускается — встроенную (сохранённая удаляется).
- **Прошивка** — `Update` из ядра ESP32 потоком, проверка SHA-256 до `Update.end()`.
- **Скачивание — в своей задаче FreeRTOS**: `loop()` не блокируется; во время обновления колонка
  работает как обычно.
- **В приложении:** в панели колонки — версия прошивки, «Обновить прошивку…» (файл `.bin`: Arduino
  IDE «Экспорт бинарного файла» или `tools/build.sh`) и ход обновления; в «Прогонах» обучения —
  «На колонку» (модель прогона). Колонка со старой прошивкой — пояснение, что первый раз нужна
  прошивка 0.5.0 по USB.

## Не делаем

Автоматическое обновление всех колонок, подпись прошивки, откат по кнопке (старая прошивка остаётся
в другой половине, но переключение назад — бэклог).
