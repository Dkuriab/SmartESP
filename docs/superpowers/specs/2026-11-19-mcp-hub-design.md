# MCP-хаб и первые коннекторы — дизайн

Дата: 2026-11-19. Этап 3 дизайна ядра (раздел 6.7). Владелец: «запускай
сейчас, параллельно, проверим всё разом на устройстве» — решения ниже приняты
без отдельного обсуждения, их можно поправить.

## 1. Зачем

Кузя должен делать простые вещи, нужные постоянно: записывать (что взвесил,
список покупок), точно считать (поделить на порции, перевести единицы), ставить
таймеры. Принцип владельца: **никакого кода под конкретную функцию в ядре** —
каждая возможность — отдельный лёгкий MCP-коннектор на том же Mac; ядро знает
только общий механизм.

## 2. Цели, не-цели, анти-цели

**Цели**
- Ядро запускает коннекторы по настройкам, отдаёт их инструменты модели,
  выполняет вызовы, показывает состояние в приложении.
- Коннектор может сам попросить Кузю сказать что-то (таймер сработал) — общий
  канал, не код под таймеры.
- Три первых коннектора: `notes` (заметки и списки), `calc` (счёт и единицы),
  `timers` (таймеры и напоминания).

**Не-цели (позже)**
- Люди (этап 4): пока все данные общие («дом»); поле `person` уже передаётся.
- Калории (`food`), музыка, умный дом, свой коннектор агентом — бэклог.
- Добавление чужого коннектора из интерфейса по команде — сейчас только
  вкл/выкл известных; чужие — правкой `config.yaml`.

**Анти-цели**
- Новая возможность требует правки ядра.
- Коннектор с доступом ко всему Mac («выполни любую команду»).
- Тишина: инструмент упал или завис — Кузя молчит.

## 3. Подходы

1. **MCP по stdio, коннектор — отдельный процесс** (выбрано; так в дизайне
   ядра): падение коннектора не роняет ядро, любой готовый MCP-сервер
   подключается тем же путём.
2. Плагины-модули внутри ядра: быстрее, но ломает изоляцию и правило
   «возможности не в ядре». Отклонено.
3. HTTP-MCP (streamable): нужен для удалённых серверов; локальным stdio
   проще. Позже, если понадобится.

## 4. Как это работает

### 4.1 Договор ядра (`contracts/tools.py`)

```python
@dataclass(frozen=True)
class ToolResult:
    text: str              # что вернуть модели
    is_error: bool = False

class ToolBox(Protocol):
    def specs(self) -> list[ToolSpec]: ...          # инструменты всех готовых коннекторов
    async def call(self, name: str, arguments: dict[str, object], person: str | None) -> ToolResult: ...
```

### 4.2 Хаб (`smartesp/tools/`, модуль ядра)

- Запускает каждый включённый коннектор (`command`, `args`, `env`) через
  `mcp` SDK (stdio), спрашивает список инструментов.
- Окружение коннектора: `SMARTESP_CONNECTOR_DATA=<data>/connectors/<id>`
  (папку создаёт хаб) + `env` из настроек.
- Имена инструментов — как у коннектора; совпадение у двух — второй получает
  префикс `<id>_`, в журнал предупреждение.
- `call`: предел 15 с; ошибка, таймаут, коннектор упал — `ToolResult` с
  `is_error=True` и понятным текстом («Коннектор «Таймеры» не отвечает»).
  Человек — в `_meta.person` вызова.
- Упавший коннектор перезапускается: 1 с, 5 с, 30 с, дальше раз в 5 мин.
- Состояние для интерфейса: `starting | ready | failed | disabled`, список
  инструментов, текст ошибки.
- **Сообщения от коннектора:** MCP-уведомление журнала (`notifications/message`)
  с `logger = "smartesp"` и `data = {"type": "announce", "text": "...",
  "person": "..."}` → хаб вызывает `on_announce(text, person, connector_id)`
  (в связке — очередь речи `notify/`). Остальные уведомления журнала — в журнал
  ядра.
- **Задачи «В работе»** (волна 3, F): то же уведомление с
  `data = {"type": "task", "id": "...", "title": "...", "status": "running",
  "eta": ..., "person": "...", "result": "..."}` → реестр ядра (`tasks/`,
  источник `connector:<id>`). `id` — строка, уникальная у коннектора
  (обязательно); `title` — что делается (обязательно у новой задачи, в обновлении
  можно не слать); `status` — `running | done | failed | cancelled` (по
  умолчанию `running`); `eta` — когда ожидается конец: секунды Unix или ISO 8601
  (без пояса — местное время); `person` — чья задача; `result` — короткий итог
  законченной. Неверное уведомление — в журнал ядра. Коннектор упал, выключен
  или убран — его идущие задачи в реестре отменяются; запустившись, коннектор
  сообщает идущие задачи заново. Конец задачи вслух — по-прежнему `announce`.
- Остановка ядра: коннекторы закрываются в пределах честной остановки.

### 4.3 Вызов инструментов моделью (`network/`)

- Участники сети с поддержкой инструментов получают инструменты хаба вместе с
  `delegate`.
- Модель вызвала инструмент (не `delegate`) → хаб выполняет → в диалог
  добавляются сообщение `assistant` с вызовом и `tool` с результатом → модель
  продолжает. Сказанное до вызова звучит сразу.
- Не больше 4 вызовов на один ответ участника; дальше — фраза
  «Не получилось выполнить действие.» (`failure`).
- Ошибка инструмента отдаётся модели текстом — она сама объяснит человеку.
- В истории хода сохраняются вызовы инструментов входного исполнителя с
  ответами (ответ — до 600 символов) перед итоговым ответом. Сначала хранился
  только текст, но живая проверка (W8) показала: без вызовов в истории модель
  в следующих ходах «выполняет» просьбы словами, не вызывая инструментов.

### 4.4 Коннекторы

Общее: `connectors/<name>/` — свой uv-проект (Python 3.12, зависимости `==`,
`mcp` SDK, FastMCP, stdio), пакет `<name>_mcp/`, тесты pytest через
клиент-сессию SDK в памяти, README (инструменты, данные, переменные). Правила
кода — как в ядре: файл ≤ 300 строк, ruff, pyright, имена английские,
комментарии и **описания инструментов — по-русски, коротко** (по ним маленькая
модель выбирает инструмент). Данные — человекочитаемые файлы в
`SMARTESP_CONNECTOR_DATA`, запись атомарная. Без сети.

- **`notes`** — заметки и именованные списки («покупки», «готовка»): добавить,
  показать, вычеркнуть, очистить, найти, удалить заметку. Хранение — Markdown.
- **`calc`** — точный счёт: выражение (безопасный разбор, не `eval`), перевод
  единиц (г/кг, мл/л, ложки, стаканы; для ложек и стаканов — плотность
  нескольких частых продуктов). Ответ — число с разумным округлением.
- **`timers`** — таймеры с именами и напоминания на время: поставить,
  сколько осталось, отменить. Сработал → уведомление `announce`
  («Таймер «картошка»: время вышло.»). Таймеры переживают перезапуск
  коннектора (файл); пропущенный за время простоя — объявляется один раз с
  пометкой «пропущен».

### 4.5 Настройки и интерфейс (после текущего плана)

```yaml
connectors:
  - id: notes
    name: Заметки
    command: uv
    args: [run, --project, <repo>/connectors/notes, notes-mcp]
    enabled: true
```

Три наших коннектора — в настройках по умолчанию, включены. Раздел применяется
на лету (хаб перезапускает изменившиеся коннекторы, сеть пересобирается с
новым списком инструментов). В приложении — панель «Коннекторы»: состояние,
инструменты, вкл/выкл. В ленте хода — какие инструменты вызывались.

**Настройки коннектора в приложении (волна 3, раздел B).** Коннектор объявляет
поля, которые владелец меняет в приложении, файлом `connectors/<id>/smartesp.json`
(папка — `--project` из `args` после подстановки `{repo}`; файл только читается):
`{"settings": [{key, title, type: text|path|list|secret|flag, hint}], "note", "example"}`
(note и example — пояснение и пример для config.yaml, только показ). Через API
(`PATCH /config`, `connectors: [{id, enabled?, env?}]`) меняются только объявленные
ключи `env`, и только со своим префиксом (`[A-Z][A-Z0-9_]*`, id заглавными с `_` вместо
прочих символов плюс `_`: `WEATHER_`, `MAC_MEDIA_`); остальное файл объявить не может
(пропуск с предупреждением). Значения — строки до 500 символов без управляющих символов
и разделителей строк, `path` —
с `/` или `~/`, `list` — `имя=путь;…` с существующими папками, `flag` — `"1"` или `""`,
`secret` в ответах — `•••`, и `•••` назад не перезаписывает значение. Вторая линия —
запрет `PATH`, `HOME`, `SHELL`, `SHELLOPTS`, `PS4`, `BASH_*`, `PYTHON*`, `DYLD_*`, `LD_*`,
`UV_*`, `PIP_*`, `NODE_*`, `XDG_*`, `GIT_*`, `*_PROXY`, `SSL_*`, `LC_*` и т. п. (полный
список — `core/README.md`) даже при подходящем префиксе. Остальное (команда, аргументы, новые коннекторы) — по-прежнему
только `config.yaml`. `GET /connectors` отдаёт `settings` с текущими значениями; панель
коннектора строит по ним форму, сохранение перезапускает только этот коннектор.
`claude_tasks` настроек не объявляет (решение W3-3): папки и инструменты Клода через токен
дали бы правку любых файлов или оболочку — только `config.yaml`, панель показывает `note`.
Подробно — `core/README.md`, «Коннекторы».
