# Коннекторы, вторая партия — короткий дизайн

Дата: 2026-11-19. Владелец: «можно ли ещё параллельно взять задачи». Блоки 2 и 4
бэклога и источник штрихкодов для `food`. Всё — отдельные MCP-коннекторы по
общим правилам (`2026-11-19-mcp-hub-design.md`, 4.4); в ядре и приложении
ничего под эти функции нет.

## 1. `claude_tasks` — мост к Клоду (бэклог, блок 2)

«Кузя, попроси Клода …» → фоновая задача Claude Code на Mac; статус голосом;
готово — Кузя говорит сам (уведомление `announce`, как у таймеров).

- Запуск: `claude -p "<задача>" --output-format json` в **разрешённой папке**.
  Папки — только из настроек коннектора: `CLAUDE_TASK_FOLDERS` =
  `имя=путь;имя=путь` (например `smartesp=/Users/…/SmartEsp`). Нет папок — ответ
  «Не настроены папки для задач Клода». Задачу без названной папки — в первую.
- Права: режим без вопросов только для правок в папке (`--permission-mode
  acceptEdits`), список инструментов Claude Code ограничен настройкой
  `CLAUDE_TASK_TOOLS` (по умолчанию `Read,Edit,Write,Glob,Grep` — без Bash и
  сети). Никаких `--dangerously-skip-permissions`.
- Инструменты: `task_start(task: str, folder: str = "")` → «Передала Клоду:
  «…». Скажу, когда закончит.»; `task_status(name: str = "")` — идёт/готово/
  ошибка + время; `tasks()` — последние 5; `task_result(name)` — короткий итог
  (первые 2–3 предложения ответа Claude); `task_cancel(name)`.
- Не больше 2 задач одновременно; предел времени задачи — 30 мин (настройка).
- Готово → `announce` «Клод закончил «<имя>»: <одна фраза итога>.»; ошибка →
  «Клод не справился с «<имя>»: <причина>.».
- Задачи и их вывод — в `SMARTESP_CONNECTOR_DATA` (журнал на диске).

## 2. `mac_media` — управление звуком на Mac (бэклог, блок 4)

Узкие инструменты, никакого «выполни любой AppleScript».
- `media_play_pause()`, `media_next()`, `media_previous()` — системные
  медиа-клавиши (любой плеер).
- `media_now_playing()` — что играет (системное «Сейчас играет»; если
  недоступно — из Music.app/Spotify через их AppleScript, если запущены).
- `volume_get()`, `volume_set(percent: int)`, `volume_change(delta: int)` —
  громкость выхода Mac.
- `output_devices()`, `output_set(name: str)` — список и выбор устройства вывода
  (JBL по Bluetooth, AirPlay, динамики); через CoreAudio (pyobjc) — без внешних
  программ.
- `music_play(query: str)` — Music.app: поиск в своей медиатеке и запуск;
  Spotify — если установлен (на этом Mac нет — тесты с подделкой).
- Всё, что требует разрешения macOS (Автоматизация), при отказе — честный ответ
  «Нет разрешения управлять <приложением>».
- Тесты — с подделками системных вызовов; живая проверка — владельцем.

## 3. `food`: штрихкоды без VPN

Open Food Facts из России без VPN не открывается (владелец). Цепочка по
штрихкоду: своя база → **barcode-list.ru** (название товара по коду; запросы
поштучные, не чаще раза в 10 с, как разрешает их robots.txt; кэш) → название
сопоставляется со встроенной таблицей → иначе спросить ккал на 100 г.
Open Food Facts — включается настройкой `FOOD_OFF=1` (по умолчанию выключен).
