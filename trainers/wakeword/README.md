# Набор для обучения «Слово пробуждения» (microWakeWord)

Обучает модель слова пробуждения для колонки — того же формата, что «Миранда» (потоковая
TFLite Micro int8, вход [1, 3, 40]). Дизайн — `docs/superpowers/specs/2026-11-22-training-design.md`.

Всё делается на том Mac, где работает ядро: там записи с колонок и голоса для синтетики.

## Цели

Каждая цель — отдельная модель: «Откликаться на» и «Не откликаться на». Начальные — в
`smartesp.json` («Кузя» и «Эй, Кузя»); владелец правит их во вкладке «Обучение» приложения
(хранятся в `~/SmartEsp/training/wakeword/targets.json`). Записи с колонок —
`~/SmartEsp/training/wakeword/recordings/<фраза>/<человек>/NNNN.wav`.

## Шаги

Из папки `trainers/wakeword` (первый раз — `uv sync`, ставится TensorFlow, ~1 ГБ):

```bash
uv run wakeword download                 # 1. данные, один раз: качает ~7 ГБ, на диске ~25 ГБ
uv run wakeword synth --target kuzya     # 2. синтетика фраз цели голосами ядра (~10 мин)
uv run wakeword train --target kuzya     # 3. обучение: признаки ~10 мин + 10000 шагов ~30 мин
uv run wakeword embed --run last         # 4. модель → прошивка (ModelData.cpp) и сборка
```

- **download** — (нужно ~25 ГБ свободного места) готовые отрицательные признаки авторов microWakeWord (речь, тишина, застолье;
  CC-BY-NC-4.0 — только для личного использования) и фоны для аугментации: эхо комнат (MIT RIR),
  музыка (FMA xs), звуки (AudioSet). Всё — в `~/SmartEsp/training/cache`.
- **synth** — каждая фраза цели (и «да», и «нет») голосами, которые ядро уже скачало (Silero,
  Vosk, Piper из `~/SmartEsp/voices`), с «!» и «?», разной скоростью и высотой: ~315 клипов на
  фразу. Идёт в окружении ядра (`core/`); готовые клипы не пересчитываются. Больше голосов в
  приложении — разнообразнее синтетика.
- **train** — клипы → аугментация (шум, музыка, эхо, сдвиг) → признаки → обучение mixednet
  (`--steps`, по умолчанию 10000; 300 шагов на M2 — около минуты; `--reuse-features` —
  переобучить без пересчёта признаков). Живые записи весят больше синтетики; каждая 5-я живая
  запись человека отложена только для проверки. Итог — `~/SmartEsp/training/wakeword/runs/<время>-<цель>/`:
  `model.tflite`, `manifest.json`, `result.json`, `log.txt`.
- **embed** — пишет `firmware/SmartEsp/src/wake_word/ModelData.cpp` из прогона (порог — из
  замера) и собирает прошивку `tools/build.sh`, если есть arduino-cli. Прошивка колонки — по USB.

## Как читать итог (result.json)

- `recall` — какую долю слов модель узнала на проверочных клипах (синтетика + отложенные живые);
- `false_per_hour` — ложных срабатываний в час на записи застолья (порог выбран так, чтобы их было
  не больше 0,5 в час, а пропусков — меньше всего);
- `real_heard` — сколько отложенных живых записей узнано: самое честное число для вашего голоса;
- `real_negative` — сколько записей «Не откликаться на» модель ошибочно приняла за слово;
- `cutoff` — порог для прошивки.

Сравнивайте прогоны «Кузя» и «Эй, Кузя» по этим числам и встраивайте лучший.
