# Набор для обучения «Слово пробуждения» (microWakeWord)

Обучает модель слова пробуждения для колонки — того же формата, что «Миранда»
(потоковая TFLite Micro int8, вход [1, 3, 40]). Дизайн —
`docs/superpowers/specs/2026-11-22-training-design.md`.

`smartesp.json` — описание набора для ядра: название, подсказка при записи и цели по
умолчанию (каждая цель — отдельная модель: «Откликаться на» и «Не откликаться на»).
Владелец правит цели во вкладке «Обучение» приложения; правка хранится в
`~/SmartEsp/training/wakeword/targets.json`.

Записи с колонки — `~/SmartEsp/training/wakeword/recordings/<фраза>/<человек>/NNNN.wav`
(16 кГц, моно; тот же микрофон и шумоподавление, что у слова пробуждения).
